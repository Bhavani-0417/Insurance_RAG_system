# Contributing

1. Open an issue describing the bug or proposed change.
2. Create a focused branch.
3. Keep changes small and document behavioural changes.
4. Add or update tests.
5. Run checks locally.
6. Open a pull request with reproduction steps and test results.

Do not commit secrets, private insurance documents, personal data, vector indexes, model weights, or generated outputs. Do not claim model accuracy without a reproducible evaluation.
